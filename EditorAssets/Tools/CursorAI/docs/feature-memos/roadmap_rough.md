# ロードマップ下書き（コピペ用）

「（以下に貼る）」の下に `[大]` / `〇中` / `・小` だけを貼る（本文行なし）。取り込み後、このファイルは `roadmap_rough_old.md` に退避され、空のテンプレが再生成される。

## 書き方（例）

```
[大見出し1]

[大見出し2]
〇中見出し2-1
・小見出し2-1-a
・小見出し2-1-b
```

| 下書き | 意味 | `roadmap.md` |
|--------|------|----------------|
| `[テキスト]` | 大見出し（角括弧。**`<>` は使わない**） | `## テキスト` |
| `〇テキスト` | 中見出し | `### テキスト` |
| `・テキスト` | 小見出し | `- [ ] テキスト` |
